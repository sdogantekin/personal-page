# Personal Page

Serkan Dogantekin's personal website — [serkandogantekin.com](https://serkandogantekin.com)

About, résumé, projects, and writing, in a single-page site with a small easter-egg game in the footer.

## Stack

Plain HTML/CSS/JS — no framework, no build step, no dependencies.

## Running locally

```
python3 -m http.server 8934
```

Then open `http://localhost:8934/index.html`.

## Deploy

Hosted on Vercel, deployed from this repo's `main` branch.
